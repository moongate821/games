# ゲーム置き場

ブラウザで遊べるゲーム。

- 入口: https://moongate821.github.io/games/
- DROP PARTY: https://moongate821.github.io/games/drop-party/ — TERRARIUM GENESIS と QUANTUM DROP の2本立て落ち物パズル。ひとり・CPU対戦・デモ観戦。
- WORLD BUILD DROP: https://moongate821.github.io/games/world-build-drop/ — 言葉を落として物語を編む落ち物パズル。合体して章を完成させよう。
- アリスの小さな大冒険: https://moongate821.github.io/games/alice/ — クレヨン画の絵本をめくって進む分岐ゲーム。結末は40種類。
- Dungeon Explorer: https://moongate821.github.io/games/dungeon/ — 3Dの迷宮を進むダンジョンRPG。街・カジノ・闘技場つき。セーブは端末に保存。
- 1980s GALAXY SHOOTER: https://moongate821.github.io/games/starfighter/ — ワイヤーフレームの宇宙を飛ぶ3Dシューティング。横向きで遊びます。
- RALLY X SURVIVORS: https://moongate821.github.io/games/rally-x/ — 止まらない車で迷路を走り、敵を引き連れて煙幕で玉突き。レベルアップで武器が増えるサバイバル。
- 王子さまと四十の夕日: https://moongate821.github.io/games/prince/ — ちいさな星の王子さまの、クレヨン画の絵本ゲーム。結末は40種類。
- 桃太郎と四十のきびだんご: https://moongate821.github.io/games/momotaro/ — おなじみの昔話を、選んで進むクレヨン画の絵本ゲームに。結末は40種類。
- 銀河鉄道と四十の切符: https://moongate821.github.io/games/ginga/ — 星の汽車に乗って、夜空をめぐるクレヨン画の絵本ゲーム。結末は40種類。
- ともしびと四十の手紙: https://moongate821.github.io/games/tomoshibi/ — 書き下ろし。灯台の灯りと、迷子の手紙の、すこしさびしくて、さいごはしあわせな絵本ゲーム。
- ミミと四十の帰り道: https://moongate821.github.io/games/mimi/ — 書き下ろし。おいていかれたぬいぐるみが、家へ帰るまでの絵本ゲーム。
- ユキと四十の足あと: https://moongate821.github.io/games/yuki/ — 書き下ろし。春にとけてしまう雪の子と、窓ごしの友だちの絵本ゲーム。
- ねこのレストランと四十のメニュー: https://moongate821.github.io/games/neko/ — 書き下ろし。子ねこのコックと、ドラゴン・おばけ・宇宙人のお客。切り絵の絵本ゲーム。
- ダンボールロケットと四十の星: https://moongate821.github.io/games/rocket/ — 書き下ろし。段ボールのロケットで、月のうさぎにケーキをとどける。段ボール工作の絵本ゲーム。
